# Отчёт по рефакторингу стилей

Основание: [`01-design-audit.md`](./01-design-audit.md).

## Выполнено

### Дизайн-токены

- Цвета интерфейса сведены к семантическим CSS custom properties: primary, page, surface, text, inverse text, overlay и focus.
- Общие тени и радиусы вынесены в токены; удалены случайные Figma-переменные с fallback из компонентных стилей.
- Шкала типографики приведена к измеренным значениям аудита: `16/24` для основного текста и `20/28`, `28/36`, `32/40`, `36/44` для заголовков.
- Контейнер ограничен `1370px`, а системные внешние отступы и вертикальный ритм переключаются на контрольных ширинах.
- Удалены неиспользуемые motion-токены и чрезмерные speculative-наборы размеров, которые не применялись в проекте.

### Базовые стили и компоненты

- Общая типографика переведена на токены `Manrope` и `Sangha Kali`.
- Секции используют единые `--page-gutter` и `--section-space` вместо комбинации чисел и отдельных media overrides.
- Навигация, карточки, табы, точки слайдеров и glass-панели используют общие цвета, радиусы и тени.
- В стилях слайдеров мест и курортов устранено межфайловое дублирование: каждый блок теперь владеет только своими селекторами.
- Убраны пустые селекторы и сокращены повторяющиеся background-декларации.
- Пустой `contacts.scss` сохранён как обязательная точка входа сборщика и снабжён поясняющим комментарием.

### Декоративные изображения

- Все чисто декоративные изображения создаются как CSS backgrounds на элементах с `aria-hidden="true"`.
- Динамические декорации истории страны и визового блока больше не выводятся через `<img>`; URL передаются в CSS через `--decor-image`.
- Статические декорации (`dragon`, `flower`, `girl`) используют тот же background-подход.
- Смысловые изображения не изменялись: hero, карточки партнёров, курорты, места, погода и контентные pictorial остаются изображениями, так как несут визуальный контент или управляют crop/responsive-поведением.
- Декоративные слои не участвуют в accessibility tree и не принимают pointer events.

## Удалено как лишнее

- Неиспользуемый файл `src/styles/tokens/_motion.scss` и его импорт.
- Неиспользуемые layout-токены `layout-gap-*` и `content-gap-*`.
- Неиспользуемые speculative typography-токены и их breakpoint-переопределения.
- Дублирующие правила `.country-places__container` и `.country-places__slide` из файла курортов.
- Пустой `.country-weather__text` и устаревшие Figma custom-property aliases.

## Проверка

- `npm run check` — успешно.
- `npm run build` — успешно.
- `git diff --check` — успешно.

## Примечания

- Существовавшие до рефакторинга изменения в Pug и JavaScript сохранены и не откатывались.
- Desktop container `1370px` основан на inferred-значении аудита. После появления доступа к измеряемым внутренним desktop layers его следует подтвердить.
- Отдельного tablet-макета нет; контрольные ширины `769`, `1024`, `1280` и `1440` требуют визуальной регрессии на реальном контенте.
